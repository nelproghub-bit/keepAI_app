🚀 HOW TO START THE APPLICATION

Step 1: START THE BACKEND
--------------------------
Double-click this file: start_backend.bat

Wait for this message:
  ✅ KeepAI Ready!
  INFO: Uvicorn running on http://0.0.0.0:8000

⚠️  Keep this window OPEN while using the application!


Step 2: OPEN STUDENT PORTAL
----------------------------
Double-click this file: student_portal.html

Or open in browser:
  Chrome, Firefox, or Edge


Step 3: REGISTER OR LOGIN
--------------------------
• New students: Click "Register Student" tab
• Existing users: Use Sign In tab
• Demo account: arnel / password123

🆘 COMMON ISSUES

Issue: "Python is not recognized"
Fix: Install Python 3.8+ from python.org
     ✅ Check "Add Python to PATH" during install

Issue: "ModuleNotFoundError"
Fix: Run in Command Prompt:
     cd c:\xampp\htdocs\keepAI_app
     pip install -r requirements.txt

Issue: "Port 8000 already in use"
Fix: Close other backend instances
     Or restart your computer
