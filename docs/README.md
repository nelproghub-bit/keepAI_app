# Documentation

Documentation is grouped by audience and purpose:

- [Admin guides](admin/): dashboard instructions, checklists, and panel references.
- [Setup guides](setup/): AI provider configuration, server startup, networking, and troubleshooting.
- [Student guides](students/): student portal, dashboard, and quick-start instructions.
- [Development references](development/): testing guidance, change summaries, and navigation notes.

Database setup files are in [`database/`](../database/): [`database_schema.sql`](../database/database_schema.sql) and [`migrate_student_dashboard.sql`](../database/migrate_student_dashboard.sql).

The [project README](../README.md) contains the application overview and quick start. Application pages, deployment configuration, and convenience startup scripts remain at the project root because the hosting setup and UI depend on those paths.
