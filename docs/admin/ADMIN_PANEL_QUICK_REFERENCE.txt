THE 4 CONTROL BUTTONS
================================================================================

🟢 START SERVER
  └─ Click to: Launch the backend server
  └─ Result: Opens new command window, server starts
  └─ Time: 3-5 seconds until ONLINE
  └─ Status: Green badge, shows uptime

🔴 STOP SERVER
  └─ Click to: Gracefully shut down server
  └─ Result: Server stops, port 8000 released
  └─ Time: 1-2 seconds until OFFLINE
  └─ Status: Red badge, uptime resets

🟠 RESTART SERVER
  └─ Click to: Stop then start server
  └─ Result: Full reboot sequence
  └─ Time: ~10 seconds until ONLINE again
  └─ Status: Red briefly, then Green

🔵 CHECK STATUS
  └─ Click to: Manually verify server status
  └─ Result: Instant status update
  └─ Time: < 1 second response
  └─ Status: Badge shows current state

READING THE LOGS
================================================================================

Format: [HH:MM:SS] message (type)

Types:
  (info)    Blue   - Information messages
  (success) Green  - Successful operations
  (warning) Orange - Operations in progress
  (error)   Red    - Errors or failures

Example Log Output:
  [10:30:00] System initialized (info)
  [10:30:05] Status: ONLINE - Server running (info)
  [10:30:10] Starting server... (warning)
  [10:30:15] Server startup initiated (success)

TYPICAL WORKFLOW
================================================================================

STARTING SERVER:
  1. Click: "Start Server" (Green button)
  2. Wait: New command window opens
  3. Wait: 3-5 seconds for server to boot
  4. See: Status turns GREEN

STOPPING SERVER:
  1. Click: "Stop Server" (Red button)
  2. Wait: 1-2 seconds for shutdown
  3. See: Status turns RED
  4. See: Uptime resets to --:--:--
  5. Done: Server is OFFLINE

RESTARTING SERVER:
  1. Click: "Restart Server" (Orange button)
  2. Wait: ~10 seconds for restart
  3. See: Status goes RED then GREEN
  4. See: Uptime resets then counts up
  5. Done: Server is ONLINE again

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Port 8000 already in use"
  → Kill existing process or stop server first
  → Or restart computer
  → Or check: netstat -ano | findstr :8000

Problem: Status stays RED after clicking Start
  → Wait longer (up to 10 seconds)
  → Click "Check Status" button
  → Check new command window for errors
  → Verify virtual environment exists

Problem: Buttons don't respond
  → Refresh browser (F5)
  → Try "Check Status" first
  → Check browser console (F12)
  → Verify port 8000 is available

Problem: Can't see server window
  → Check taskbar or task switcher
  → Alt+Tab to find it
  → Or restart and try again
